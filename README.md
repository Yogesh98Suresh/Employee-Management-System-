# Employee Management System

A simple **Employee Management System** built using **HTML, CSS, and JavaScript**. This project allows users to add and manage employee information through a simple and user-friendly interface.

### Features

* Add new employees
* Display employee details in a table
* Store newly added employees using `localStorage`
* View total employee count on the dashboard
* Delete employees
* Department and salary information
* Responsive and simple user interface

### Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser LocalStorage

### Project Purpose

This project was created to practice **frontend development, JavaScript DOM manipulation, forms, tables, and localStorage** while building a practical Employee Management System.
